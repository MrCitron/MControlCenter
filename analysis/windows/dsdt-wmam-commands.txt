Mecanique : WMRD(i) = out(i,0x360) ; in(0x361). WMWT(i,v) = out(i,0x360); out(v,0x361).
WMAM(Arg0, Arg1=commande, Arg2=buffer[0]=IPAR puis BS00..BS30):
  IPAR = index de sous-groupe (0,1,2,...) ; resultats dans BL01..BL31.
Les commandes vont par PAIRES : lecture = impair, ecriture = pair suivant.
